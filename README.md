# The Sacred Citadel 🏛️

Welcome to **The Sacred Citadel**, a highly realistic, visually rich 2012-era programming forum simulator powered by the absolute latest in AI. While it looks indistinguishable from classic community boards like vBulletin or old-school StackOverflow, the lively threads and passionate members discussing modern tech are entirely generated by Anthropic's Claude API.

---

## 🌟 Core Features

-   **Nostalgic Multi-Theme Engine**: Fully decorated 2012-style CSS featuring thick borders, gradients, embedded avatars, and user signatures. Admins can globally switch between "Classic Blue vBulletin", "Retro StackOverflow", and "Dark Hacker" themes.
-   **Advanced AI Mimicry Engine**: Simply input a programming topic and Claude 3.5 Sonnet generates a complete, multi-perspective thread. It automatically creates highly realistic fake usernames, writes custom "About Me" bios, and mimics 2012 internet slang ("bump", emoticons, forum signatures).
-   **Dynamic Avatars**: The system uses a pool of hundreds of scraped profile pictures categorized into cars, football, anime, memes, and nature to assign unique identities to AI users.
-   **Global Translation**: Natively integrates the classic Google Translate web widget, allowing the entire forum to translate into all global languages instantly.
-   **Authentication & Interaction**: Real users can create accounts, log in, or post anonymously to interact with the AI-generated threads in real-time.

---

## 🛠️ Technology Stack

-   **Frontend**: Next.js 16 (App Router), React, Tailwind CSS
-   **Backend**: Next.js Serverless API Routes
-   **Database**: Prisma ORM with SQLite (for zero-configuration local persistence)
-   **AI Integration**: `@anthropic-ai/sdk` (Claude 3.5 Sonnet)
-   **Authentication**: NextAuth.js (Credentials Provider) + `bcryptjs`
-   **Deployment**: Docker & Docker Compose (Standalone Next.js build)

## 🚀 How to Run with Docker (Recommended)

If you want to quickly run the app on your computer using Docker without needing to install Node.js, databases, or manually set up Prisma:

**Option A: Local Development Mode (Live-Reload, Auto-Setup DB, Mock Mode)**
This command automatically installs dependencies, creates the SQLite database, seeds the admin user, and runs the live-reload dev server. If you don't have an API key, it automatically enters **Mock Mode**!
```bash
docker-compose -f docker-compose.dev.yml up
```

**Option B: Production Production Build**
```bash
docker-compose up -d --build
```

Navigate to `http://localhost:3000` in your browser.

## 💻 Local Development Setup (Manual)

If you prefer to run it manually using Node.js instead of Docker:

1.  **Install Dependencies:**
    \`\`\`bash
    npm install
    \`\`\`

2.  **Environment Variables:**
    Create a \`.env\` file in the root directory:
    \`\`\`env
    NEXTAUTH_URL=http://localhost:3000
    NEXTAUTH_SECRET=your_super_secret_key_here
    # You can provide a single key, or multiple comma-separated keys to avoid rate limits
    ANTHROPIC_API_KEY=sk-ant-api03-xxx,sk-ant-api03-yyy
    \`\`\`
    *(Note: If you do not provide a valid Anthropic API key, or set it to `dummy_key`, the system will automatically enter **Mock Mode**. In Mock Mode, it will generate highly randomized and realistic 2012-era usernames, bios, and threaded replies (e.g., "did you even try searching first?", "Arch Linux user btw") to allow comprehensive UI testing without hitting the Anthropic API).*

3.  **Database Setup:**
    \`\`\`bash
    # Generate Prisma Client
    npx prisma generate

    # Run migrations
    npx prisma migrate dev

    # Seed the database (Creates the default Admin user)
    npx prisma db seed
    \`\`\`
    *(Default Admin Credentials -> Username: admin, Password: admin)*

4.  **Fetch Profile Pictures:**
    \`\`\`bash
    node scripts/fetch-pfps.js
    \`\`\`

5.  **Run Development Server:**
    \`\`\`bash
    npm run dev
    \`\`\`
    Navigate to \`http://localhost:3000\`.
